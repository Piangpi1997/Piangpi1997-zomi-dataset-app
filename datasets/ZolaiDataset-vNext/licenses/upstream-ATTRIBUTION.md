# Attribution and source acknowledgement

## Required dataset attribution

When redistributing or using this dataset, include:

> Zomi Monolingual Corpus v1.0, compiled and reviewed by Biak Hong (2026),
> licensed under CC BY 4.0.

If a DOI has been assigned, include it in the citation.

## Source acknowledgements

The corpus contains permissioned material from:

- **Zomi Daily** — <https://zomidaily.com/> — 354,042 retained sentences.
- **Agape Digest Magazine** — <https://www.agapedigest.com/> — 9,359 retained
  sentences; publisher identified in project records as Zomi Agape Church.

The source publishers and their contributors retain attribution for the source
material. Written permission for the requested corpus uses was confirmed
received by corpus owner Biak Hong on 2026-08-26. The permission correspondence
is retained privately and is not distributed because it may contain private
contact information.

## Changes and derived datasets

Derived releases should state what was changed, retain the permanent sentence
IDs when feasible, identify the source release as v1.0, and must not imply that
Biak Hong or the source publishers endorse the derived work.
