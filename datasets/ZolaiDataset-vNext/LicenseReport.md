# License Report

## Evidence policy

A platform license tag is a publisher claim, not proof every underlying text is covered. Repository code licenses cannot authorize unrelated scraped books, Bible translations, audio performances or personal records. Missing or conflicting rights stay quarantined. License clearance is source/file scoped; it does not clear language quality or privacy.

## Quarantine and discrepancies

All other relevant sources are REVIEW until file contents, language identity, rights chain and duplicate risk are checked. Irrelevant image/English-only/index/adapter matches are REJECT for this text workflow. All decisions, owners, dates, sizes and URLs appear in SourceManifest.json and DiscoveryReport.md.

The existing manifest has unsupported "Open Academic" wording, inconsistent live HF tags, and an unverified GitHub LianHong URL. These findings do not alter the running backend automatically. Historical manifest tags should not be used as authorization.

Existing TB77 ©1977 and TDB ©2011 Bible Society Myanmar imports require translation-specific authorization; a new uploader's CC-BY tag does not supersede those copyrights. BJB/KJV scope also needs translation/jurisdiction-specific review. No Bible-derived new source is accepted in this candidate. Exact/folded overlap with existing Bible records is excluded; incidental quotations may still remain and need contextual rights review.

CC-BY-SA tagged collections need attribution/share-alike compatibility review before any combination. CC0 claims for mirrors and scraped collections need upstream evidence; do not infer that a mirror can relicense third-party material.

## Non-corpus exclusions

SaaS users, profiles, payments, usage records, credentials, chat memory and private support records are excluded. No private publisher emails or permission correspondence were fetched or published.
